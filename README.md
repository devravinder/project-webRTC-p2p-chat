# P2P Server-less WebRTC Chat

A Zoom/Teams-style P2P Server-less WebRTC app for chat, audio/video calls, screen share, screen recording, file sharing

Hoisted on Github pages - visit [Meet](https://chat.paravartech.com/) and use it for personal chat & also available as PWA.

## How to use

1. Open/vist [Meet](https://chat.paravartech.com) app and enter your name (first visit only).
2. On the home screen pick `Call` (video/audio meeting) or `Chat` (text chat and files only — no camera or microphone).
3. To start, tap `Start Meeting` / `Start Chat`, pick max participants, and share the generated code/link with others.
4. To join, tap `Join Meeting` / `Join Chat` and enter the code you received (or just open the shared link).
5. In a call, use the control bar to chat, mute/camera toggle, share your screen, or record.
6. Tap `Leave` to exit — closing the tab works too.
